# Fal Studio

Web app per iPhone per generare immagini e video con i modelli di [fal.ai](https://fal.ai), usando la propria chiave API.

- Apri il sito da Safari → Condividi → **Aggiungi alla schermata Home**.
- Tocca **Collega fal.ai** e incolla la chiave (da https://fal.ai/dashboard/keys). La chiave resta salvata solo sul telefono.
